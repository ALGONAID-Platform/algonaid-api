# توثيق API إرسال الإشعارات والرسائل الجماعية للطلاب (لوحة التحكم)

يوضح هذا المستند كيفية ربط لوحة التحكم (Dashboard) مع الـ Endpoint المخصصة لبث الإشعارات والرسائل الجماعية للطلاب المشتركين في الكورسات، مع شرح سلوك الرسالة وتوافقها مع تطبيق الهاتف المرفوع على المتجر.

---

## إرسال إشعار عام للطلاب المشتركين (Broadcast Notification)

تُستخدم هذه الـ Endpoint من قِبل المعلم أو الأدمن لإرسال تنبيه أو رسالة عامة لجميع الطلاب المشتركين في دوراته، أو تخصيص الرسالة لطلاب كورس معين.

* **الرابط (Endpoint):** `POST /api/v1/notifications/broadcast-my-students`
* **طريقة الطلب (Method):** `POST`
* **المصادقة:** `Bearer Token` (مطلوبة)
* **الصلاحيات المسموحة:** `ADMIN`, `OWNER`
* **الترويسات (Headers):**
  ```http
  Authorization: Bearer <ADMIN_OR_TEACHER_TOKEN>
  Content-Type: application/json
  ```

---

### جسم الطلب (Request Body):

#### 1. الإرسال لجميع الطلاب في **كافة الكورسات** الخاصة بالمعلم:
*(اترك `courseId` فارغاً، وسيقوم النظام تلقائياً بإرسال الإشعار لجميع المشتركين النشطين في كافة كورساتك)*:
```json
{
  "message": "📢 تنبيه هام لجميع طلابنا الأعزاء: نود إعلامكم بتحديث جدول المراجعة، ونتمنى لكم دوام التوفيق والتميز!"
}
```

#### 2. الإرسال لطلاب **كورس محدد فقط** من كورسات المعلم:
*(إذا أردت تخصيص الرسالة لطلاب دورة معينة فقط، قم بتمرير `courseId` الخاص بها)*:
```json
{
  "message": "📢 تنبيه خاص بمشتركي كورس الرياضيات: يرجى مراجعة محتوى الوحدة السابقة وحل التكليف قبل الموعد النهائي.",
  "courseId": 5
}
```

---

### الاستجابة المتوقعة (Responses):

#### عند النجاح (201 Created):
```json
{
  "success": true,
  "message": "تم إرسال الإشعار بنجاح إلى 120 طالب",
  "recipientsCount": 120,
  "commentId": 481
}
```

#### إذا لم يكن هناك طلاب مسجلون حالياً (200 OK):
```json
{
  "success": true,
  "message": "لا يوجد طلاب مسجلين حالياً في هذه الكورسات",
  "recipientsCount": 0
}
```

#### في حال وجود خطأ في المدخلات (400 Bad Request):
```json
{
  "statusCode": 400,
  "message": [
    "نص الإشعار مطلوب"
  ],
  "error": "Bad Request"
}
```

#### في حال لم يكن للمستخدم صلاحية معلم أو ليس لديه كورسات (403 Forbidden):
```json
{
  "statusCode": 403,
  "message": "ليس لديك كورسات خاصة بك لإرسال إشعار لطلابها",
  "error": "Forbidden"
}
```

---

### خصائص وسلوك الإشعار في تطبيق الهاتف المرفوع على المتجر:

1. **الظهور في التطبيق:** يظهر الإشعار فوراً في صفحة **"الإشارات والردود"** باسم المعلم وصورته الشخصية المعتمدة مع نص الرسالة.
2. **إخفاء زر الرد:** تم برمجياً ضبط نوع الإشعار بحيث **يختفي زر الرد (أيقونة الرد) تماماً** من التطبيق، حيث إن الرسالة عامة وغير مرتبطة بدرس أو اختبار يمكن الرد عليه.
3. **التفاعل عند النقر:** عند ضغط الطالب على الإشعار، يتم تعليمه كـ **"مقروء"** فقط وتحديث العداد، دون أي انتقال لأي شاشة ودون حدوث أي خطأ أو كراش في التطبيق.
4. **عدم التكرار:** إذا كان هناك طالب مسجل في أكثر من كورس لنفس المعلم، فسيصله **إشعار واحد فقط** ولن يتكرر عليه الإشعار.
